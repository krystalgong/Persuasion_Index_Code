# Testing persuasion-index 0.3.0rc1

This release candidate fixes case-sensitive scoring, percent-expression
matching, LIWC validation and cache refresh, custom lexicon precedence, and
concurrent lexicon isolation. Please test it in a new environment rather than
upgrading an existing analysis environment in place.

## Install from TestPyPI

Install runtime dependencies from PyPI, then install only PI from TestPyPI:

```bash
python3 -m venv .venv-pi-030rc1
source .venv-pi-030rc1/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy pandas wordfreq vaderSentiment
python -m pip install \
  --index-url https://test.pypi.org/simple/ \
  --no-deps \
  persuasion-index==0.3.0rc1
```

For Jupyter, also install and register a kernel:

```bash
python -m pip install ipykernel
python -m ipykernel install \
  --user \
  --name pi-030rc1 \
  --display-name "Python (PI 0.3.0rc1)"
```

Select that kernel and restart it before running the checks below.

## Notebook acceptance checks

The LIWC and custom lexicon fixtures below are synthetic and safe to share.
They do not contain licensed dictionary content.

```python
import json
import os
import sys
import tempfile
from concurrent.futures import ThreadPoolExecutor
from importlib.metadata import version
from pathlib import Path

from persuasion_index import check_resources, score

assert version("persuasion-index") == "0.3.0rc1"
print(sys.executable)

# 1. Case-sensitive components receive the original capitalization.
apa = score("Smith (2020) found that the intervention worked.")
assert apa["Evidence"]["attribution"] == 1.0

cased = score("The plan is GREAT and the results are good.")
lowered = score("the plan is great and the results are good.")
assert (
    cased["Sentiment"]["vader_compound"]
    > lowered["Sentiment"]["vader_compound"]
)

# 2. Ordinary percentage expressions remain valid statistical evidence.
for text in ("20%", "20% of adults", "It fell 20%.", "3.5%", "20 percent"):
    assert score(text)["Evidence"]["statistical"] > 0.0

with tempfile.TemporaryDirectory() as temp_dir:
    root = Path(temp_dir)

    # 3. LIWC can be configured after an earlier score in the same kernel.
    liwc_path = root / "synthetic-liwc.dic"
    previous_liwc = os.environ.get("PI_LIWC_FILE")
    os.environ["PI_LIWC_FILE"] = str(liwc_path)
    try:
        before = score("furious")
        assert before["Sentiment"]["anger"] == 0.0

        liwc_path.write_text(
            "I: me\n"
            "You: you\n"
            "Anger: furious\n"
            "Sad: sad\n"
            "Anx: worried\n"
            "Posemo: happy\n"
            "Past: was\n"
            "See: see\n"
            "Ppron: they\n",
            encoding="utf-8",
        )
        after = score("furious")
        assert after["Sentiment"]["anger"] > 0.0
        assert check_resources()["liwc"]["available"] is True

        # 4. doctor rejects a file that exists but is not parseable.
        liwc_path.write_text(
            "this is not a LIWC dictionary",
            encoding="utf-8",
        )
        assert check_resources()["liwc"]["available"] is False
    finally:
        if previous_liwc is None:
            os.environ.pop("PI_LIWC_FILE", None)
        else:
            os.environ["PI_LIWC_FILE"] = previous_liwc

    # 5. A custom lexicon is honored without changing process environment.
    custom_path = root / "custom.json"
    custom_path.write_text(
        json.dumps({"ARG_CLAIM": ["zorb"]}),
        encoding="utf-8",
    )
    custom = score("zorb", lexicon_file=custom_path)
    assert custom["Argumentation"]["conclusion_explicitness"] > 0.0

    # 6. Concurrent custom lexicons remain isolated.
    other_path = root / "other.json"
    other_path.write_text(
        json.dumps({"ARG_CLAIM": ["beta"]}),
        encoding="utf-8",
    )

    def repeated(path):
        return [
            score("zorb", lexicon_file=path)["Argumentation"][
                "conclusion_explicitness"
            ]
            for _ in range(30)
        ]

    with ThreadPoolExecutor(max_workers=2) as pool:
        matching_future = pool.submit(repeated, custom_path)
        missing_future = pool.submit(repeated, other_path)
        matching = matching_future.result()
        missing = missing_future.result()

    assert all(value > 0.0 for value in matching)
    assert all(value == 0.0 for value in missing)

print("persuasion-index 0.3.0rc1 acceptance checks passed")
```

## What to report

Please include:

- operating system and Python version;
- installation command and whether it was a fresh environment;
- output from `persuasion-index doctor --json` with private paths redacted;
- the smallest text that reproduces an unexpected score;
- whether the issue occurs with `expanded`, `seeded`, or a custom lexicon.

Never attach or commit a licensed LIWC dictionary or other restricted resource.
